# 视觉参考记录

本项目的视觉方向参考了公开的 Awwwards 与 FWA 案例分类，具体取舍如下。

## 参考来源

- [Awwwards / Data Visualization](https://www.awwwards.com/websites/data-visualization)：参考数据可视化作品将复杂信息转为首屏叙事的方式。
- [Awwwards / Sound-Audio](https://www.awwwards.com/websites/sound-audio)：参考音乐类站点的节奏感、声音主题和大字号排版。
- [Awwwards / Sites of the Day](https://www.awwwards.com/websites/sites_of_the_day)：参考 Experimental、Music & Sound、Gestures / Interaction 等筛选维度。
- [FWA / The Musical Forest](https://thefwa.com/cases/the-musical-forest-a-webvr-experiment)：参考“点击与探索形成反馈”的交互思路，本项目将其收敛为数据筛选、图表联动和卡片悬浮反馈。
- [FWA / Pandora - Sounds Like You](https://thefwa.com/cases/pandora-sounds-like-you)：参考音乐数据与个体感受结合的叙事方式，本项目使用评论情绪、词频和城市节点表达样本感受。

## 落地原则

- 不复制案例的图片、源码或品牌元素。
- 使用数据控制室作为项目形态，保证登录、后台、图表和推荐均能真实运行。
- 使用深色底、酸性黄、珊瑚橙和青绿色作为信号色，避免单一蓝紫色界面。
- 使用非对称分栏、细线网格和仪表盘式首屏，让数据成为视觉主角。
- 使用本地 Lucide 图标，不使用 emoji 作为按钮或状态图标。
- 动效控制在 150–700ms，并遵循 `prefers-reduced-motion`，不让动画遮挡数据阅读。
