# 本科项目范围与论文证据规范

## 1. 题目与开题报告优先
项目实现以《基于Python的演唱会数据分析与可视化系统设计与实现》开题报告为依据。新增内容必须服务于数据采集、清洗、存储、分析或可视化，不为了显得复杂而增加无关模块。

## 2. 结论必须有数据依据
- 论文中不填写尚未实际采集的条数、准确率、响应时间和图表结果。
- 每批数据记录来源、采集时间、原始文件名和清洗后条数。
- 公开页面动态加载或无法稳定访问时，不强行绕过；改用合规快照并在论文中说明。
- SnowNLP 情感结果只作定性分析，不能写成经过人工标注验证的高精度模型。

## 3. 最小可交付主线
1. 获取公开演唱会基础信息和评论快照。
2. 完成缺失值、重复值、日期、票价和文本清洗。
3. 写入 MySQL，并保留 CSV 中间结果。
4. 完成词频统计、关键词和 SnowNLP 情感倾向计算。
5. 用 Flask + ECharts 展示筛选结果。
6. 用功能测试、数据质量统计和运行截图支撑论文。

## 4. 文档要求
技术文档使用中文，术语首次出现时给出英文或缩写。论文正文区分“系统已实现”“计划实现”和“后续改进”，避免把规划内容写成已完成结果。
